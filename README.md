# TrackHub

## Описание проекта

TrackHub представляет собой мобильное приложение для платформы iOS, предназначенное для отслеживания и планирования физических тренировок. Приложение разработано с использованием SwiftUI и следует современным принципам разработки iOS-приложений, включая паттерн MVVM (Model-View-ViewModel).

## Основные возможности

### Управление учетными записями
- Регистрация новых пользователей с полной валидацией данных
- Аутентификация пользователей через защищенный API
- Автоматическое обновление токенов доступа при истечении срока действия
- Безопасное хранение учетных данных в Keychain

### Работа с тренировками
- Просмотр каталога упражнений с подробными описаниями
- Создание индивидуальных тренировочных программ
- Организация упражнений в тренировки
- Планирование тренировок на неделю
- Детальная информация о каждом упражнении, включая целевые группы мышц и необходимое оборудование

### Профиль пользователя
- Управление личной информацией
- Просмотр статистики тренировок
- Настройка уведомлений
- Система рейтинга для тренеров

### Поиск и навигация
- Продвинутая система поиска упражнений и тренировок
- Фильтрация по группам мышц и оборудованию
- Интуитивная навигация между разделами приложения

## Технический стек

### Основные технологии
- **Язык программирования**: Swift 5
- **Фреймворк UI**: SwiftUI
- **Минимальная версия iOS**: iOS 14.0 и выше
- **Управление зависимостями**: Swift Package Manager

### Архитектура
Приложение построено по принципу MVVM (Model-View-ViewModel) с четким разделением слоев:

- **Models**: Определение структур данных (Exercise, Workout, Plan, User)
- **Views**: Пользовательский интерфейс на SwiftUI
- **ViewModels**: Бизнес-логика и управление состоянием
- **Services**: Сетевой слой и внешние сервисы

### Используемые библиотеки
- **SwiftKeychainWrapper**: Безопасное хранение токенов и конфиденциальных данных
- **URLSession**: Сетевые запросы к REST API

## Модели данных

### Exercise (Упражнение)
Представляет отдельное упражнение с полной информацией о его выполнении:
- Уникальный идентификатор
- Название и описание
- Целевые группы мышц
- Необходимое оборудование
- Инструкции по выполнению
- Медиа-контент (изображения и видео)
- Параметры выполнения (подходы, повторения, время отдыха)

### Workout (Тренировка)
Коллекция упражнений, объединенных в одну тренировочную сессию:
- Уникальный идентификатор
- Название и описание
- Список упражнений
- Автор тренировки
- Дата создания

### Plan (План тренировок)
Организация тренировок по дням недели:
- Уникальный идентификатор
- Название и описание
- Расписание тренировок по дням недели
- Автор плана
- Дата создания

### User (Пользователь)
Профиль пользователя приложения:
- Уникальный идентификатор
- Электронная почта
- Имя и фамилия
- Аватар
- Рейтинг (для тренеров)
- Дополнительная информация (пол, роль, контактные данные)

## Сетевое взаимодействие

### API Service
Приложение взаимодействует с RESTful API через централизованный сервис `APIService`. Основные возможности:

#### Аутентификация
- `POST /users/account/login/` - Вход в систему
- `POST /users/account/` - Регистрация нового пользователя
- `POST /users/token/refresh/` - Обновление токена доступа

#### Управление токенами
- Автоматическое добавление Bearer-токена к запросам
- Перехват ошибок 401 (Unauthorized)
- Автоматическое обновление истекших токенов
- Повтор неудавшихся запросов после обновления токена

#### Безопасность
- Хранение токенов в iOS Keychain
- Шифрование конфиденциальных данных
- Защита от несанкционированного доступа

## Система тем

Приложение поддерживает кастомизацию пользовательского интерфейса через систему тем. Темы определяют:
- Основные цвета интерфейса
- Цвета фона
- Цвета кнопок и элементов управления
- Цвета текста (основной, вторичный, дополнительный)

Система тем реализована через протокол `Theme` и управляется классом `ThemeManager`.

## Установка и запуск

### Требования
- macOS 12.0 или выше
- Xcode 13.0 или выше
- Swift 5.5 или выше
- iOS 14.0 или выше (для запуска на устройстве)

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone <URL-репозитория>
cd TrackHub-FrontEnd
```

2. Откройте проект в Xcode:
```bash
open "Tracker Hub.xcodeproj"
```

3. Дождитесь автоматической установки зависимостей через Swift Package Manager.

4. Настройте целевое устройство или симулятор в Xcode.

5. Запустите проект (⌘R).

### Конфигурация API

По умолчанию приложение настроено на работу с локальным сервером разработки:
- Базовый URL: `http://127.0.0.1:8000`

Для изменения адреса API необходимо обновить URL в файле `APIService.swift`:
```swift
let urlString = "http://your-api-url.com"
```

## Разработка

### Добавление новых функций

При добавлении новой функциональности рекомендуется следовать текущей структуре:

1. Создайте новую папку в директории `Features/`
2. Организуйте код по паттерну Model-View-ViewModel:
   - `Model/` - модели данных
   - `View/` - UI компоненты
   - `ViewModel/` - бизнес-логика

3. При необходимости добавьте переиспользуемые компоненты в `Core/Components/`

### Работа с темами

Для добавления новой темы:

1. Создайте новый файл в директории `Themes 2/`
2. Реализуйте протокол `Theme`
3. Добавьте новую тему в массив `ThemeManager.themes`

### Добавление новых моделей

Все модели должны соответствовать следующим требованиям:
- Соответствовать протоколу `Codable` для сериализации
- Соответствовать протоколу `Identifiable` для использования в SwiftUI
- Иметь четкую структуру с типизированными полями
